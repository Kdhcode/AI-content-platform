# 공통 협업 규칙

- Claude Code는 구현, Codex CLI는 독립 리뷰를 담당한다.
- 작업 요구사항과 완료 기준은 TASK.md에 기록한다.
- 구현자는 작은 단위로 커밋한다. 자동 리뷰는 저장만 한 파일을 감지하지 않는다.
- 리뷰 결과의 근거를 확인한 후 수정한다. 리뷰 의견을 무조건 적용하지 않는다.
- 테스트 삭제, 검사 완화, 가짜 AI 결과로 통과시키지 않는다.
- 테스트 결과에는 실행 명령, 기준 커밋, 통과/실패/미실행을 명시한다.
- 요약 사실성, 이슈 분류 정확도는 사람이 정답을 정한 평가 세트로 검증한다.
- 수정 반복은 최대 3회. 미해결 문제는 기록하고 사용자에게 전달한다.
- 동일 작업을 두 기기에서 동시에 수행하지 않는다. 전환 전 commit/push, 전환 후 pull.
- API 키, 비밀번호, 상세 로그는 Git에 올리지 않는다.
