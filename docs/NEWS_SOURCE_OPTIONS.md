2026-10-25 작성(TASK.md 34절), 같은 날 2차 보완(TASK.md 35절: 공공누리 제1유형 원문, 실제 공공자료 2건). **조사만 했다.** 각 기관의 공개 페이지를 브라우저로 열어 본문을 읽었다. 문의 메일·전화, 회원 가입, 계약, 유료 결제, API 키 발급·호출, 기사 수집은 하지 않았다. 이용 가능 여부를 확정하지 않으며, 법적 판단도 하지 않는다. 설계 쪽 맥락은 [NEWS_INPUT_PLAN.md](NEWS_INPUT_PLAN.md).

표기: **확인** = 아래 URL 본문에서 직접 읽은 내용(요지, 확인 날짜 2026-10-25) / **추정** = 확인한 내용에서 미루어 본 것 / **미확인** = 찾지 못했거나 확인하지 않은 것.

## 1. 무엇을 위한 자료인가

- **NEWS:** 이슈를 바탕으로 쓰는 뉴스 콘텐츠. AI 초안 구조는 핵심 요약 · 사건 개요 · 주요 내용 · 배경 · 현재 상황 · 추가 확인사항(명세 02 §9, `CONTENT_A_PLAN.md` 80행).
- **LIFE:** 기존 명세의 "생활 이야기" 콘텐츠. 하나의 이슈에서 NEWS와 별도로 만들 수 있고(`NEXT_CONTENT_SCOPE.md` 20행, "명세 §생활 이야기"), 구조는 실제 사례 · 생활과의 관련성 · 관련 정보/기술 · 알아둘 점이다(`CONTENT_A_PLAN.md` 80행). 기사 분석 카테고리의 `LIFE`(생활 정보, `DECISIONS.md` 59행)와는 다른 개념이다. 이 이상의 정의는 저장소에서 찾지 못해 덧붙이지 않는다(노션 명세 원문은 저장소에 없음).
- 지금 부족한 것: 발췌형 RSS에는 배경·수치·인용과, LIFE에 필요한 대상·기간·방법 같은 정보가 거의 없다(`NEWS_INPUT_PLAN.md` 2·4절).

## 4-1. 공공누리 제1유형 이용조건 원문 확인 (2026-10-25)

근거(모두 2026-10-25 본문 확인):
- 유형 안내: https://www.kogl.or.kr/info/license.do (제1유형·AI유형 탭)
- 제1유형 일반증서와 이용약관 탭: https://www.kogl.or.kr/info/licenseType1.do — 일반증서는 이용약관과 유형 안내를 이해하기 쉽게 요약한 것이라고 스스로 밝히므로, 같은 페이지의 "공공누리 이용약관" 탭 본문을 함께 읽었다
- AI유형 일반증서 https://www.kogl.or.kr/info/licenseTypeAi.do 는 링크만 확인했고, AI유형 조건은 유형 안내의 AI유형 탭 본문으로 읽었다

| 항목 | 확인한 내용(요지) |
|---|---|
| 상업 이용 | 상업적 활용 여부와 관계없이 무료로 자유롭게 이용 가능. 영리 목적 이용 가능 |
| 변경 | 2차적 저작물 작성 등 변형 이용 가능. 단 저작인격권을 존중하는 범위 안에서(침해 예시: 외설 광고에 이용해 명예 훼손, 연구 성과·통계 수치를 수정해 착오 유발, 사진을 잘라 원래 표현과 현저히 다르게 만듦) |
| 출처 표시 | 이용 시 출처 또는 저작권자 표시 의무(예시 문구 형식 제공). 온라인에서 가능하면 출처 웹사이트 하이퍼링크 제공 의무 |
| 이용 시 의무 | 공공기관이 후원하거나 특수한 관계인 것처럼 오인하게 하는 표시 금지. 조건 중 하나라도 위반하면 이용허락이 자동 종료되고 즉시 이용을 중단해야 함. 위반 후 계속 이용하면 저작권 침해로 민·형사 책임 가능 |
| 공공기관 면책 | 정확성이나 지속적 제공을 보장하지 않음. 이용으로 생긴 손해에 책임지지 않음 |
| 조건 변경 | 이용조건은 바뀔 수 있으나, 변경 전에 이용했다면 해당 저작물은 용도 변경 없이 계속 이용 가능. 기관에서 별도 이용허락을 받으면 공공누리 조건을 적용하지 않아도 됨 |
| 제외되는 권리 | 제1유형 이용약관·일반증서에서 **제외 권리를 정한 명시 조항은 찾지 못함**. 실제 제외 범위는 **자료 쪽 표시**로 확인됨 — 정책브리핑 보도자료는 "텍스트에 한하여" 적용, 사진·이미지·일러스트·동영상은 대부분 정책브리핑에 저작권이 없어 해당 저작권자 허락 필요. 제3자 권리·상표·개인정보 등에 대한 공공누리 차원의 일반 조항은 **미확인** |
| 외부 AI 처리 — 명시 조항 | 제1유형 조건에는 **AI에 관한 문구가 없다.** 별도의 **AI유형**(인공지능 학습용)이 있다: AI유형 표시 저작물은 "인공지능 학습용 데이터"로 이용할 경우에 한해 출처 표시 없이 상업적으로도 자유이용 가능하고, 조건은 ① 원저작물과 같거나 실질적으로 유사한 산출물이 생성되지 않도록 기술적 조치 ② 산출물이 직접 인용하면 출처 명시를 위한 기술적 조치 ③ 학습한 모델의 상업 이용은 가능하나 학습용 데이터 재판매 금지. AI유형은 제1~4유형과 **함께 표시**하는 유형이고, AI 학습용이 아닌 목적이면 함께 표시된 기존 유형 조건을 따라야 한다. "인공지능 학습용 데이터"는 「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」 제2조제12호의 "인공지능의 개발·활용 등에 사용되는 데이터"라고 안내 |
| 외부 AI 처리 — 해석이 필요한 부분 | 아래는 원문으로 결론이 나지 않는다. **"AI 언급 없음"을 허용으로도 금지로도 해석하지 않는다.** (1) 이 프로젝트의 사용은 모델 학습이 아니라 OpenAI API에 텍스트를 넣어 요약·구조화하는 것(`NEWS_INPUT_PLAN.md` 3-2절)인데, 이것이 제1유형의 일반적인 "이용·변형"인지, AI유형이 정한 "인공지능 학습용 데이터(개발·활용 등에 사용)"로 보아야 하는지. 법률 정의에 "활용"이 들어 있어 분석 입력도 포함된다고 읽힐 여지가 있다 (2) 후자라면 AI유형 표시가 없는 제1유형 자료는 AI 활용 목적으로는 별도 허락이 필요한지 (3) AI 결과물을 공개할 때 제1유형 출처 표시를 어떤 형태로 해야 하는지(원 보도자료 링크로 충분한지) |

**구체적인 문의 질문(발송하지 않음, 보낼지는 사용자가 판단):**
- 받는 곳: 공공누리 제도 — 한국문화정보원(공공누리 사이트의 질문과 답변 또는 대표전화), 정책브리핑 게시 자료 — 문화체육관광부 정책포털과
1. 공공누리 **제1유형만** 표시된 정부 보도자료 텍스트를, 모델 학습에 쓰이지 않는 외부 생성형 AI API에 입력해 요약·항목 정리를 하는 것이 제1유형의 이용 범위에 들어갑니까, 아니면 AI유형 표시가 있어야 합니까?
2. AI유형 안내의 "인공지능 학습용 데이터(인공지능의 개발·활용 등에 사용되는 데이터)"에 **추론 시 입력(프롬프트)으로 넣는 것**이 포함됩니까?
3. 그 결과물(요약과 원문 링크)을 상업적 웹사이트에 게시할 때, 출처 표시는 원 기관명·보도자료 제목·정책브리핑 링크를 적는 것으로 충분합니까?
4. (정책브리핑) RSS 중단 이후 보도자료 텍스트를 프로그램으로 받아 오는 방법 중 허용되는 방식(공공데이터포털 API 등)이 있습니까? 웹 페이지를 자동으로 읽어 오는 것은 허용됩니까?
