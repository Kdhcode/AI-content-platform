표기: **확인** = 아래 URL 본문에서 직접 읽은 내용(요지, 확인 날짜 2026-10-25) / **추정** = 확인한 내용에서 미루어 본 것 / **미확인** = 찾지 못했거나 확인하지 않은 것.

## 1. 무엇을 위한 자료인가

- **NEWS:** 이슈를 바탕으로 쓰는 뉴스 콘텐츠. AI 초안 구조는 핵심 요약 · 사건 개요 · 주요 내용 · 배경 · 현재 상황 · 추가 확인사항(명세 02 §9, `CONTENT_A_PLAN.md` 80행).
- **LIFE:** 기존 명세의 "생활 이야기" 콘텐츠. 하나의 이슈에서 NEWS와 별도로 만들 수 있고(`NEXT_CONTENT_SCOPE.md` 20행, "명세 §생활 이야기"), 구조는 실제 사례 · 생활과의 관련성 · 관련 정보/기술 · 알아둘 점이다(`CONTENT_A_PLAN.md` 80행). 기사 분석 카테고리의 `LIFE`(생활 정보, `DECISIONS.md` 59행)와는 다른 개념이다. 이 이상의 정의는 저장소에서 찾지 못해 덧붙이지 않는다(노션 명세 원문은 저장소에 없음).
- 지금 부족한 것: 발췌형 RSS에는 배경·수치·인용과, LIFE에 필요한 대상·기간·방법 같은 정보가 거의 없다(`NEWS_INPUT_PLAN.md` 2·4절).
